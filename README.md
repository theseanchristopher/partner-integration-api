# Partner Integration API

Learning project demonstrating a unified partner API over simulated backend systems.

## Planned capabilities
- OpenAPI contracts for the unified API and two simulated backends
- Request validation, routing, and data transformation
- Synchronous request processing
- Asynchronous processing with SQS
- Idempotency, retries, and dead-letter queues
- CloudFormation deployment and CloudWatch logging

## Local environment
conda activate partner-api

## AWS region
us-east-1
