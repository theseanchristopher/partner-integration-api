03 / SYSTEM DESIGN
Behind the response
The deployed architecture. Internal steps are explanatory, not live traces.


Three authentication boundaries
01
Client → unified API
Cognito issues a JWT access token. API Gateway validates the token and required scope; Lambda checks merchant and component access.
02
Unified service → A
The calling Lambda signs its HTTPS request with IAM role credentials. Component A's API Gateway enforces SigV4 and invoke permission.
03
Unified service → B
The Lambda retrieves an encrypted client certificate and key from SSM Parameter Store. Component B's custom domain requires mTLS and trusts its CA certificate in S3.




What this demonstrates
Contract mapping · authentication · sync/async processing · atomic idempotency · retries · processing DLQ handling
Current scope
Backend merchant data is simulated. Polling is implemented. Webhooks, certificate rotation tooling, and richer tracing remain planned.
